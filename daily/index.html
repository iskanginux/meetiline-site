Install

Two ways, both take a minute

The usual way

Download Meetiline Daily
  1. Open the file and drag Meetiline Daily to Applications.
  2. Open it. If macOS says “Meetiline Daily” Not Opened, press Done.
    Not Move to Trash: nothing is wrong.
  3. Open System Settings › Privacy & Security, scroll to the bottom and press Open Anyway.
    Press it once more in the window that follows.

Meetiline Daily is not yet signed with an Apple Developer ID, so macOS asks once.

Show me the windows

One line in Terminal

Installs it in Applications and opens it. No warning.

curl -fsSL https://meetiline.iskan.kz/daily/install | sh

Open Terminal (⌘ Space, type Terminal), paste, press Return.

See what it does
  1. Checks your Mac is supported.
  2. Downloads the latest Meetiline Daily and checks its checksum.
  3. Puts it in Applications.
  4. Lets macOS open it without a warning.
  5. Opens it. Nothing else is changed.

First launch

Allow the microphone, the sound of call apps, the screen and notifications. It then downloads the speech model once (about 0.6–0.9 GB); after that it works offline. Keep the app in Applications.
